# Prueba técnica de lista con scroll infinito con Flutter

Este proyecto esta consumiendo una api publica para traer productos y poder listarlos. 

# Versiones
- Flutter 3.38.6
- Dart 3.10.7
- DevTools 2.51.1

# Ejecucion
Despues que se tenga el path de flutter podemos ejecutar nuestro poryecto de la siguiente forma, dentro del proyecto ejecutamos el comando en la terminal o en el bash "flutter doctor" alli nos dira si esta todo bien, en el caso de no tener androidStudio se puede correr la aplicacion como de escritorio o con el apk probarlo en un dispositivo movil. Con el comando "flutter run" ejecutamos nuestro proyecto de forma local. Recomendación usar el Apk.
